# Student Attendance System

A simple student attendance application built with React, Vite, and JavaScript.

## Features

- Add and delete students
- Mark students present or absent
- Record attendance separately for each date
- Search students by name
- View live attendance totals
- Keep data in browser local storage
- Download the selected date's attendance as a JSON file

## Run the project

1. Install [Node.js](https://nodejs.org/).
2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in the terminal.

## Other commands

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
