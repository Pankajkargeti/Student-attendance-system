# Student Attendance System

A simple and interactive **Student Attendance System** built using **HTML, CSS, and JavaScript (DOM Manipulation)**.

This project allows users to add students, mark attendance, delete students, and save attendance records.

---

## Features

- Add new students
- Mark students as Present or Absent
- Delete student records
- Automatic attendance summary
- Save attendance data as JSON file
- Dynamic table updates using DOM manipulation
- Responsive and clean UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

---

## Project Preview

The interface includes:

- Student name input field
- Add Student button
- Save Attendance button
- Attendance table
- Present/Absent toggle
- Delete option
- Attendance summary section
